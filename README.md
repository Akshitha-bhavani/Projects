## Projects

### 1. Real-Time Hand Gesture Recognition System

**Technologies:** Python, OpenCV, MediaPipe, NumPy

A real-time computer vision application that uses a webcam to detect hand landmarks and recognize predefined hand gestures.

**Recognized Gestures:**

* Peace ✌️
* Point ☝️
* Fist ✊
* Open Palm 🖐️
* Thumbs Up 👍

**Key Concepts:**

* Real-time video processing
* Hand landmark detection
* Gesture classification
* Computer vision
